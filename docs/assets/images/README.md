# Imagens do alojamento

Coloque os ficheiros com estes nomes para aparecerem automaticamente no site:

- `logos/logo-02.png` - logo marrom no cabeçalho
- `logos/logo-03.png` - logo branca no rodapé e favicon
- `quartos/apartamento-deluxe/` - fotos usadas na galeria do Apartamento Deluxe
- `quartos/queen-deluxe/` - fotos usadas na galeria do Quarto Queen Deluxe

As dez fotos existentes do Apartamento Deluxe e as oito fotos do Quarto Queen Deluxe já estão ligadas às galerias em `docs/quartos.html`. Para adicionar imagens, coloque-as na pasta correspondente e acrescente uma miniatura com o caminho e o texto alternativo em `docs/quartos.html`.
